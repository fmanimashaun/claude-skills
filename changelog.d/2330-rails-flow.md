section: rails-flow
- **`docs_layout.py --write` rewrites every spelling of a moved path, or names what it left — `plugins/rails-flow/scripts/docs_layout.py`** (#2330). After a move it now also rewrites a directory named without its trailing slash (`mkdirSync(join(root, "docs/progress"))`, a JSON `_comment`) and a directory built from `join()` segments (`"docs", "inventory"`), keeping the quote and separator style. It then scans the whole tree with a loose pattern, independent of the rewrite passes, and names every old spelling still there (`LEFT <file>:<line> still names …`) as a problem instead of reporting `0 problem(s)`. The three flo-it-ui shapes are selftest fixtures, plus a string concatenation that must be named as LEFT.
