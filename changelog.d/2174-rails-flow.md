section: rails-flow
- **Behaviour change: the migration guard and rubocop auto-correct hooks moved to rails-stack — `plugins/rails-flow/hooks/hooks.json`** (#2174). `guard-migrate.sh` (refuses a new `db/migrate/*.rb` written by `Write`) and `lint-ruby.sh` (rubocop auto-correct after a `.rb` edit) left rails-flow for `plugins/rails-stack/hooks/`, so a Next.js project installing rails-flow no longer runs Rails hooks. **A Rails project that has rails-flow installed but not rails-stack no longer gets either hook, and nothing warns it**: no `plugin.json` can declare a required plugin. The fix is to install rails-stack; the toolchain audit (#2168) is to flag a Rails project missing it. With both installed, behaviour is unchanged.
