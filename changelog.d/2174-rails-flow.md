section: rails-flow
- **The migration guard and rubocop auto-correct hooks moved to rails-stack — `plugins/rails-stack/hooks/`** (#2174). `guard-migrate.sh` (refuses a new `db/migrate/*.rb` written by `Write`) and `lint-ruby.sh` (rubocop auto-correct after a `.rb` edit) and their `hooks.json` entries left `plugins/rails-flow/hooks/hooks.json`, so a Next.js project installing rails-flow no longer runs Rails hooks. Behaviour is unchanged. A project that installs rails-flow without rails-stack no longer gets either hook; no `plugin.json` can declare a required plugin, so the toolchain audit (#2168) is what tells it.
