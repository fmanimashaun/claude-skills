section: Repository hygiene
- **The misdescribed-agents rule reads each plugin's own manifest as well — `scripts/lint_self_consistency.py`** (#1945). It read only `.claude-plugin/marketplace.json`, so the class #653 was written for (a description that names some agents but not all, or a wrong stated count) stayed invisible in `plugins/<name>/.claude-plugin/plugin.json`, where it found two instances at once (design-flow naming 3 of 5, rails-flow claiming eleven of thirteen). Five selftest scenarios cover the manifest (some, all, none, a wrong count, and valid JSON that is not an object, which crashed the sibling `marketplace-version-duplicate` rule and is fixed there too, along with its `lstrip("./")` of the source path) and `scripts/mutations/lint_self_consistency.py` has two mutants: one stops reading the manifest, one stops comparing the stated count. Our own design; no framework claim.
