- **The git shim lets a downstream project's own spec fixtures stage their temp repositories: a repository marked with `.git/rails-flow-fixture` inside `TMPDIR` may `git add -A` and set its own `core.hooksPath` — `plugins/rails-flow/git-shim/git`, `plugins/rails-flow/scripts/git_shim_selftest.py`, `plugins/rails-flow/reference/downstream-spec-fixtures.md`** (#1999). Retask's 41 git-using specs ran git from the repository's directory and were refused, because the #1994 exemption only understood `GIT_DIR`/`GIT_WORK_TREE`. It now also judges the repository git will use from the cwd or `-C`, accepts the marker in a linked worktree's common dir, and allows `init.defaultBranch`. The five bypasses closed on #1994 stay closed (selftest rows and eight new mutants). Our own design: the maintainer's decision is recorded on #1999.
