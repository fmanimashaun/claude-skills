section: rails-flow
- **Fourteen Rails project gates are no longer in rails-flow — `plugins/rails-flow/checks.json`** (#2175). `simple-form-only`, `tenancy-cop`, `production-config`, `mcp-end-to-end`, `i18n-wired`, `ci-runs-tests`, `spec-support-wired`, `coverage-ratchets`, `layer-structure`, `structure-ratchet`, `unauthenticated-writes`, `erb-lint`, `erb-parse-safety` and `architecture-boundaries` (14 rows, 12 scripts, their 12 mutation guards and the tenancy scaffold) moved to rails-stack, so a project on another stack does not carry them. Nothing about them changed: against the Retask repository `project_gates.py --list` gives the same 55 rows with the same states before and after (14 now owned by rails-stack), and the moved scripts that run without a Ruby toolchain print the same output and exit with the same status from either location. Four gates stay in rails-flow for now because each imports a file that stays: `migration-order` (the coordinator's `session_coordinator.py`, #2183), and `privacy-inventory`, `mcp-personal-fields` and `mcp-annotations` (the schema reader in `build_project_wiki.py`, #2177). They move with that file. A project with rails-flow and no rails-stack installed now runs 20 checks instead of 34.
