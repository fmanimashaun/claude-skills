section: rails-flow
- **The Rails project gates are no longer in rails-flow — `plugins/rails-flow/checks.json`** (#2175). `simple-form-only`, `migration-order`, `tenancy-cop`, `privacy-inventory`, `production-config`, `mcp-annotations`, `mcp-end-to-end`, `mcp-personal-fields`, `i18n-wired`, `ci-runs-tests`, `spec-support-wired`, `coverage-ratchets`, `layer-structure`, `structure-ratchet`, `unauthenticated-writes`, `erb-lint`, `erb-parse-safety` and `architecture-boundaries` (18 rows, 16 scripts, their 16 mutation guards and the tenancy scaffold) moved to rails-stack, so a project on another stack does not carry them. Nothing about them changed: against the Retask repository `project_gates.py --list` gives the same 55 rows with the same states before and after (18 now owned by rails-stack), and 15 of the 16 moved scripts (all but `herb_lint.py`) print the same output and exit with the same status from either location. A project with rails-flow and no rails-stack installed now runs 16 checks instead of 34.
