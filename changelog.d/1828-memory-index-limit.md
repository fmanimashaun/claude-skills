- **A check measures the auto-memory index against what Claude Code loads of it, and the SessionStart hook says so when it is near — `plugins/rails-flow/scripts/check_memory_index.py`, `plugins/rails-flow/hooks/scripts/session-start.sh`, `plugins/rails-flow/commands/setup-flow.md`, `docs/evidence/upstream/claude-code.json`, `plugins/rails-flow/scripts/mutations/check_memory_index.py`** (#1828, slice 2 of #1685). `doctrine-verifier` read https://code.claude.com/docs/en/memory live on 2026-10-10 (verdict CONFIRMED): "The first 200 lines of `MEMORY.md`, or the first 25KB, whichever comes first, are loaded at the start of every conversation. Content beyond that threshold is not loaded at session start." The page gives no byte unit; the unit is **25,000 bytes, confirmed by the harness's own warning** ("MEMORY.md is 24.5KB (limit: 24.4KB) … 1 of 159 lines were cut off": 24.4 KB in 1024-byte units is 25,000 bytes). An earlier version of this change inferred 25,600 bytes from one index that appeared to load whole at 25,248 bytes; that was wrong and is corrected here (recorded on #1828). The script measures lines and bytes, warns at 80% of either (160 lines, 20,000 bytes), reports "over" past either limit with how many lines are not loaded, and treats exactly 200 lines and exactly 25,000 bytes as still loaded whole. An index already over the limit would be red on day one, so `--baseline FILE` fails only on growth past a recorded size (`--record` writes it, nothing else does). It finds the index through `autoMemoryDirectory` (project, then user settings) or the default under `~/.claude/projects/<path with non-alphanumerics as dashes>/memory/`. `--hook-line` prints one line only when the index is near or past the limit and always exits 0; the SessionStart hook calls it, silent otherwise, since that hook re-fires after every compaction. One registry row re-reads the sentence weekly, a doctor gate runs the selftest (28 checks), and 17 mutations in `plugins/rails-flow/scripts/mutations/check_memory_index.py`, all caught. Version boundary: the page carries no per-feature version for this limit.
