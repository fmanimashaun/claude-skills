- **k6 and ZAP are refused for a host that is not this machine — `plugins/qa-flow/scripts/check_local_target.py`** (#1954, found by the qa-flow audit). "NEVER production" was a sentence in `perf-tester.md`, `security-scanner.md` and `certify.md` with nothing behind it, so k6 load or a ZAP scan ran against whatever `$QA_BASE_URL` held. The `perf-tester` and `security-scanner` agents now run the check before every k6 or ZAP command; it applies the robot's own parsed-host rule (`robot_descriptor.local_url`, one home) and exits 2 for a non-loopback host, a URL with userinfo (`https://127.0.0.1:x@prod.example.com`), a missing target or an unparsable one. A staging host is an explicit, audited opt-in that names the host (`QA_ALLOW_REMOTE_TARGET=staging.example.com`, an exact match: not a yes, not a suffix), and userinfo is refused even then. It is a tripwire on the documented path, not a boundary: an agent that skips the step is not stopped. Guard `check_local_target`: 16 verdict cases and 4 command-line cases, 5 mutants, and a `doctrine_map.py` row.
