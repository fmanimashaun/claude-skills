section: Repository hygiene
- **The Linux check installs zsh and asserts it, and `git_shim_selftest.py` says when its zsh row did not run — `scripts/linux_check.sh`, `scripts/linux_check_selftest.py`, `scripts/mutations/linux_check.py`, `plugins/rails-flow/scripts/git_shim_selftest.py`** (#1971, the host-tools audit after #1964). I ran every selftest that reaches a `node`, `ruby`, `perl`, `zsh`, `shasum` or `gh` lookup in the container and on macOS. One read green when it should not: `git_shim_selftest.py` passed 313 checks in the container against 314 on macOS, because its zsh row ran only `if shutil.which("zsh")` and the container had none. zsh joins `HOST_PACKAGES` and `CANARY_TOOLS`, so the container runs the row (314). Where zsh is absent anyway, the row prints that it did NOT run and is not counted. Two mutants (zsh not installed, the canary not asking for it) are caught. Every other lookup fails loudly, prints an explicit skip, or reads the same in both places (the table is on the PR). Our own design: the coordinator's assignment on #1971.
