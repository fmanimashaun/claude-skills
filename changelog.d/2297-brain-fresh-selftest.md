section: rails-flow
- **The brain-fresh selftest no longer reads the runner's branch — `plugins/rails-flow/scripts/check_brain_fresh.py`** (#2297, found on the v1.159.0 arm PR #2313). `check_brain_fresh.py --when arm` takes an arm from `GITHUB_HEAD_REF`, which in CI on an arm PR is `chore/arm-vX.Y.Z`; the selftest's child process inherited it, so the "not an arm" fixture was an arm and the selftest refused. Each fixture now runs in a hermetic environment with every branch signal (`GITHUB_HEAD_REF`, `GITHUB_REF_NAME`, `GITHUB_REF`, `GITHUB_BASE_REF`) removed, and a new case sets the runner's own environment to an arm and still expects exit 3. Reproduced on the previous commit (`GITHUB_HEAD_REF=chore/arm-v1.159.0` on a branch of that name: one failure, exit 1) and green on this one; one new mutant (the fixture inherits the runner's signals) is caught.
