section: Repository hygiene
- **`mutation_check.py` reads an unmutated selftest as STARVED only when every failure line in it is a timeout row — `scripts/mutation_check.py`, `scripts/mutation_check_selftest.py`, `scripts/mutations/mutation_check_harness.py`** (#2014, refs #2000, found reviewing #2011). `selftest_timed_out()` was a substring test, so a real failure row beside one timeout row read STARVED (exit 3, a skip) and hid an INERT guard behind a loaded machine. A selftest tally line is not a failure; any other failure-shaped line is. A selftest fixture with a real failure beside a timeout and a mutant that restores the substring test. Our own design.
