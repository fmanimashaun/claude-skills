- **The degraded-PATH release-gate fixtures say when their precondition fails — `plugins/rails-flow/scripts/check_hook_gates.py`, `scripts/mutations/check_hook_gates_harness.py`** (#1929). The hook takes the repository to be the outermost ancestor of its working directory holding a `.git` or a `Gemfile` and drops every PATH entry inside it, so `bare_gate`'s tool directory was tested as a PATH only while nothing above `$TMPDIR` was one; on a machine where something is, every tool read as missing and the fallback mutant survived with no word of why. `repo_marker_above` now decides it: a check fails by name with the offending directory, and the helper is driven with a `.git` and with a `Gemfile` above a scratch directory, with two harness mutants (each marker ignored) that die on those checks. Not covered, stated: the fixture check's wiring to the helper is not mutated, because a mutant needs an ambient marker the guard's tempdir does not have. Our own design; no framework claim.
