section: Repository hygiene
- **A gate keeps the two registry readers answering the same — `scripts/check_registry_reader_parity.py`, `scripts/mutations/check_registry_reader_parity.py`, `scripts/maintainer_doctor.py`** (#1857). qa-flow'"'"'s `check_requirements.py` and rails-flow'"'"'s `check_registry_closed.py` each read the same registry grammar (plugins install alone, so neither can import the other); the gate runs both over nine samples, valid and malformed (a BOM, a nested value, a bad line), and fails when their entries or problems differ. Its selftest feeds a reader that disagrees, and three mutants break the comparison. Our own design; no framework claim.
