Owner rule 2026-10-11: "every feature must have a way to test it end to end". Downstream a `@real-signin` Playwright spec passed on the dev runner while the image runner'"'"'s `--grep "@qa-image"` never selected it, and nothing flagged the missing path. A registry entry with `feature: true` must be named (its id in a test title, a describe title or a `tag` option) by an active spec test that at least one declared runner selects; a spec no runner picks up counts as missing. The runners are the files under `e2e_paths: runners:` in `qa/qa.config.yml`; their `--grep`/`-g`, `--grep-invert`/`-G` and positional file filters and the config'"'"'s top-level `grep`/`grepInvert` are read as Playwright documents them (verified 2026-10-11 against https://playwright.dev/docs/test-cli, /test-annotations and /api/class-testconfig). What the docs do not state is not assumed: a repeated `--grep`, a command-line grep combined with a config grep, a grep built from a shell variable, a pattern with named groups or lookbehind, a config `testMatch`/`testIgnore` or a project-level filter, and any `web_e2e` other than Playwright each make the verdict "could not check" (exit 3), never a pass and never a hidden finding. Shell comments are stripped so a comment that says `playwright test` is not a runner. Unselected features may sit on a baseline that only shrinks (`--base` as in #1855). Checked against Retask'"'"'s real runners and spec in a scratch copy. Twenty-three mutants, each caught by the row that names it. Stack: Playwright only today.
