- **A feature needs an end-to-end test that a runner actually selects, by Playwright's own listing — `plugins/qa-flow/scripts/check_e2e_paths.py`, `plugins/qa-flow/scripts/mutations/check_e2e_paths.py`, `plugins/qa-flow/scripts/check_requirements.py`, `plugins/qa-flow/checks.json`, `plugins/qa-flow/commands/cases.md`, `plugins/qa-flow/scaffold/qa/e2e-unselected-baseline.txt`** (#1856, slice 2 of #1853). Owner rule 2026-10-11: "every feature must have a way to test it end to end". Downstream a `@real-signin` Playwright spec passed on the dev runner while the image runner'"'"'s `--grep "@qa-image"` never selected it, and nothing flagged the missing path. A registry entry with `feature: true` must be named (its id in a test title, a describe title or a tag) by an active test that at least one declared runner selects. The first version re-implemented Playwright'"'"'s argument parsing and an independent review found six ways it disagreed with the real thing (attached `-g@tag` values, a case-insensitive CLI grep, a config not at the default path, a `testDir` elsewhere, OR'"'"'d positional filters, `--list`), so the authority is now Playwright: each runner command is run with `--list --reporter=json` (the project'"'"'s own `npx --no-install playwright`, from the config'"'"'s directory or `e2e_paths: cwd:`) and the listed, non-skipped tests are read. A runner file is read only to FIND the commands and to refuse the ones it cannot execute safely (an argument built from a shell variable or substitution, shell control flow, a pipe, `||` or `&&` before it, a heredoc, an `exit`, an unexplained `cd`): exit 2 with the reason (the project gate runner grades 2 ERROR and 3 not applicable, which never fails a run, so \"could not check\" must not be 3), never a pass; so is a Playwright that cannot be run (not installed, a config error, no JSON). A filter that matches nothing is Playwright'"'"'s "No tests found" and an empty listing, not a failure. This is a project gate, not a hook: running the project'"'"'s own Playwright is in scope. Unselected features may sit on a baseline that only shrinks (`--base` as in #1855). The attack battery from the review runs against a real Playwright 1.64 with `--selftest --real DIR`; the mocked plumbing rows run everywhere. Thirty-seven mutants, each caught by the row that names it. Playwright only today. Our own design on the owner'"'"'s decision recorded on #1853.
