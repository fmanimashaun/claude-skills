section: pipeline
- **Two pipeline selftests write `core.hooksPath` into their own fixture repository's config file, so they run under the rails-flow git shim — `plugins/pipeline/scripts/install_git_hooks_selftest.py`, `plugins/pipeline/scripts/git_guard_selftest.py`** (#1982). Run from the Claude Code Bash tool, the git shim is first on PATH and refuses `git config core.hooksPath` everywhere, because that is how the session's own hooks would be switched off; both selftests set it with `git config` in a temp fixture repository and failed on their first case. They now append `[core] hooksPath = .githooks` to that repository's `.git/config` (a helper, `set_hooks_path`), which is what the installer and the guards under test read; both pass with the shim first on PATH and without it. Our own design; the fixture exemption in the shim covers staging and resetting a fixture's own repository, not hooks and config (the coordinator's decision on #1982).
