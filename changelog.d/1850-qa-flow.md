section: qa-flow
- **qa-flow's two hooks start `/bin/bash -p` and source `hooks/scripts/lib/trusted-env.sh` first — `plugins/qa-flow/hooks/hooks.json`, `plugins/qa-flow/hooks/scripts/lib/trusted-env.sh`** (#1850; P1 of #1843). `release-gate.sh` and `qa-status.sh` started under a `bash` the repository's settings could choose, and called `python3`, `git` and `gh` through a `PATH` it could set. The lib is rails-flow's, byte-identical (plugins install alone, so each ships a copy; the `hook-start-hardened` lint keeps them identical). Same limit: this closes a cooperating repository's redirect, not `disableAllHooks`. `release-gate.sh` reads the inherited `GH_REPO` from the lib's `RF_INHERITED_GH_REPO`, because the lib now unsets `GH_REPO` for the gate's own `gh`.
