- **The context-nudge status line shows the prompt-cache hit rate — `plugins/rails-flow/hooks/context-nudge.mjs`** (#1884, slice 3 of #1683). A `turn.step` hook reads each main-conversation request's usage and draws `context NN% · cache NN%`, where the share is `cache_read_input_tokens` / (read + `cache_creation_input_tokens` + `input_tokens`), the three input parts the mods docs list for `result.usage`. A subagent's request (`agentId` set) is skipped; the response streams through untouched; a request with no or malformed usage keeps the last reading instead of a false 0%. Drawn only, so it adds no context. 5 new unit checks (`plugins/rails-flow/tests/context-nudge.unit.mjs`, 32 in all), 4 new mutants in `plugins/rails-flow/scripts/mutations/context_nudge.py`, two existing mutants re-anchored after the status-line refactor; `plugins/rails-flow/reference/context-budget.md` explains the figure.
