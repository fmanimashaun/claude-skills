section: nextjs-stack
- **A React frontend architecture for Next.js projects, each rule enforced — `plugins/nextjs-stack/skills/react/SKILL.md`** (#2222). The `react` skill covers composition, the Server/Client boundary, data and state, streaming, performance and the frontend's share of security, in the same eight layers as the Hotwire architecture (#2223), for React 19.3 and the Next.js 16.4 App Router. Every rule was verified against react.dev and the Next.js docs on 2026-10-21 (24 claims: 23 CONFIRMED, 17 of them with corrected wording, such as "a high `"use client"` does not lose server rendering"; 1 INCONCLUSIVE and left out). Every rule names its enforcement, following the owner's ruling on #2222: lint that `eslint-config-next` already runs; `react-lint-off-by-default` (`scripts/check_react_lint.py`), which runs the three official rules the preset ships off; `react-patterns` (`scripts/check_react_patterns.py`) for what a measured eslint run missed (a client route without a declared reason, `fetch` in a client Effect, an internal `<a>`); a required declaration; or a recorded review verdict (rails-flow #2225). Both checks were measured on 27 Next.js apps; a rule that fired on correct code there was dropped.
