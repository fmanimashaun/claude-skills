section: Repository hygiene
- **A stack descriptor's `ui.implementation` must resolve to a design-flow UI adapter, and the harness finds the adapter's guards** (#2178). The new rule `ui-adapter-unresolved` in `scripts/lint_self_consistency.py` refuses a descriptor whose `ui.implementation` has no `plugins/design-flow/ui/<id>/adapter.json`, an adapter whose `id`, agents or checks do not resolve, and a descriptor `ui.porter` or `ui.composer` that disagrees with the adapter; two guard mutations in `scripts/mutations/lint_self_consistency.py` prove the agent and porter halves can fail. `scripts/mutation_check.py` now discovers guards under `plugins/*/ui/*/scripts/mutations`, staged with the plugin as their base so an adapter script still reaches design-flow's neutral `scripts/` and `brands/`; and `scripts/rails_assumptions.py` lets an adapter's guard follow the decision of the script beside it. Our own architecture decision, no framework claim.
