- **The git-shim selftest reads only the fixture's own `credential.helper`, so it passes on a machine whose system gitconfig sets one — `plugins/rails-flow/scripts/git_shim_selftest.py`** (#2073). The #2021 case asserted that `--get-all credential.helper` was exactly `store`; Xcode's system gitconfig already sets `osxkeychain`, so on a Mac the check failed ("a named credential helper did not land"), the `git shim` gate went red and the three guards that stage this selftest (`git_shim`, `git_shim_hook`, `git_shim_selftest_skip`) reported INERT. It now reads `--local`. Maintainer tooling only; the shim is unchanged.
