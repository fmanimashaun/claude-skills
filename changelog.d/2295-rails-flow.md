section: rails-flow
- **A git that does not answer in time is a named refusal of `gh pr ready`, no longer "not a repository", which is allowed — `plugins/rails-flow/hooks/scripts/lib/pr_ready_guard.py`** (#2295). `git()` returned None for both a timeout and a failure, so under load its 10 s timeout read as "not a git repository" and the gate failed open (the #2132 row got rc 0 on a loaded machine). A timeout now raises `GitTimeout`, and the hook and the `gh` shim refuse by name: "did not answer within N s, so whether this repository runs the sweep guard, and which HEAD it is on, cannot be told". A git that answers "not a git repository" is still allowed. `RAILS_FLOW_GIT_TIMEOUT` sets the limit; `plugins/rails-flow/scripts/check_hook_gates.py` drives a stub git that sleeps, in and outside a repository, `plugins/rails-flow/scripts/gh_shim_selftest.py` drives the same stall through the `gh` shim (refused by name, gh never runs), and `scripts/mutations/hook_guard_pr_ready.py` and `plugins/rails-flow/scripts/mutations/gh_shim_judge.py` each have a mutant that turns the timeout back into an allow.
