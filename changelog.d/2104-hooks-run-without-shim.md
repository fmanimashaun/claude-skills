section: rails-flow
- **The hook-gate harness drives hooks with no git-shim on PATH, as production does — `plugins/rails-flow/scripts/check_hook_gates.py`** (#2104). Measured: the Claude Code process that spawns hooks has no `git-shim` on PATH; `session-start.sh` adds it through `CLAUDE_ENV_FILE`, which reaches the Bash tool only. Run from a session, the harness inherited the shim-first PATH, so the release gate's own `git` calls went through the shim: `release_gate_refs` failed 7 of 103 and `release_gate_repos` 25 of 243 on clean dev (both green on CI), and the `hook_release_gate_refs`/`_repos` guards read INERT on a local sweep. `main()` now removes `git-shim` directories before any fixture runs; two checks pin it, one on a fixed PATH string so it fails on a machine with no shim.
