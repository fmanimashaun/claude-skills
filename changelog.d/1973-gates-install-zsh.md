section: Repository hygiene
- **CI installs zsh, so `git_shim_selftest.py`'s zsh row runs on the hosted runner too — `.github/workflows/gates.yml`** (#1973, a follow-up). PR #1974's run measured `host tool zsh: ABSENT` on `ubuntu-latest`, so the row ran only on a maintainer's machine and in the Linux check; on CI it was skipped (said, not counted). The `gates` job (the sweep) and each `mutation` shard (the `git_shim` guards) now `apt-get install` zsh and assert it is on PATH, failing the step if the install silently did not happen. `release.yml` calls this workflow (`workflow_call`), so the release sweep gets it with no second copy. The `host tool` report line still shows the runner image's own state, before the install. The coordinator's call.
