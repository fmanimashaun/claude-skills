- **The SessionStart nudge works from a subdirectory — `plugins/pipeline/hooks/scripts/pipeline-status.sh`** (#1946). The hook tested `pipeline.yml` and `qa/CERTIFICATION` against the working directory, so a session started below the repository root printed neither the post-merge QA-verify nudge nor the "dev is certified" line, and exited 0 saying nothing. It now resolves the repository top level once and reads both files under it. `plugins/pipeline/scripts/pipeline_status_selftest.py` runs the real hook from the root and two subdirectories and has controls for a repository with no `pipeline.yml` and a directory that is no repository; it is a doctor gate (`pipeline status hook`), and `plugins/pipeline/scripts/mutations/pipeline_status_hook.py` has three mutants. Our own design; no framework claim.
