- **A report of what third-party SessionStart hooks add to every session and compaction — `scripts/report_third_party_hooks.py`** (#1887, slice 5 of #1683). `check_hook_output_budget.py` ratchets the hooks we ship; the ones other plugins install are paid the same way, but we do not ship them, so this is a maintainer report, not a gate. It runs each SessionStart command of every enabled non-claude-skills plugin's newest installed version (numeric version order) in the ratchet's own fixture project, and reports stdout bytes with a token estimate; a failing or hung hook is reported with its status, never as 0 bytes. On 2026-10-12 here: superpowers 3,616 B, explanatory-output-style 1,303, remember 550, security-guidance 133 — 5,602 B (~1.4k tok) per start. It cannot see state outside the project (`remember` prints the user's memories), so the figures are a floor: the ~5.7k-token `remember` figure #1683 cited came from a real session. Its selftest is a doctor gate; mutation guard `scripts/mutations/report_third_party_hooks.py` (4 mutants, all caught). Our own design: coordinator-approved split of #1683.
