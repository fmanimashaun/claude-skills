section: core-skills (stack-neutral skills plugin)
- **A new plugin, `core-skills`: the stack-neutral skills every flow and stack uses — `plugins/core-skills/.claude-plugin/plugin.json`** (#2186, slice 1; EPIC #2162). `code-review`, `quality-pass`, `derived-artifacts` and `parallel-session-lane` moved out of `rails-stack`, so a project on any other stack no longer installs that stack's doctrine to get a code review. `rails-flow`, `rails-stack`, `nextjs-stack` and `flow-suite` each declare `core-skills` as a dependency directly: Claude Code "installs and enables the plugin's declared dependencies" (docs, plugins/install, read 2026-10-22), and no page says whether a dependency's dependencies install, so none relies on that. `dist/<skill>.skill` keep their names and bytes. `plugins/core-skills/README.md` says what moved and what to install.
