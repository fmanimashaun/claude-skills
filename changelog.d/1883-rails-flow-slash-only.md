- **`/rails-flow:toolchain-audit` and `/rails-flow:wrap` leave the always-on skills listing — `plugins/rails-flow/commands/toolchain-audit.md`, `plugins/rails-flow/commands/wrap.md`** (#1883, slice 2 of #1683). Both set `disable-model-invocation: true`, which the skills docs say means "Description not in context" (https://code.claude.com/docs/en/skills). Rule (implementer's technical call, delegated by the coordinator; reasons per command on #1883): flag a command only when a person runs it deliberately AND nothing in the plugins invokes it as a step, because a flagged command "can't be invoked by Claude on its own" (skills docs). rails-flow's always-on listing drops 8,994 → 8,496 characters (~166 tokens every session), measured by `scripts/check_always_on_cost.py`, whose baseline `scripts/always_on_baseline.json` is lowered in this change. `claude plugin details` will not show the drop: it still counts flagged commands.
