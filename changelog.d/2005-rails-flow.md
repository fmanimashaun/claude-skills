The header read added for #2003 blocked on a FIFO named `git` in a PATH directory ahead of the real git, so every git call hung; a candidate must now be a regular, executable file before it is read. `RAILS_FLOW_GIT_SHIM_DEPTH` with 7 or more digits (this shim counts to 16) printed `integer expression expected` before being judged; it now counts as zero, quietly. A selftest row and a mutant for each. Low severity: planting either needs write access to a PATH directory, which already allows a fake git. Our own design.
