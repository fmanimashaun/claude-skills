section: rails-flow
- **`security-auditor` is mandatory per threat-model row, and `gh pr ready` needs its current record — `plugins/rails-flow/scripts/check_security_review.py`** (#2119). Our-design change, no external claim. When a change adds or edits `docs/security/threat-models/<slug>.md`, the sweep (`checks.json`, id `security-review`) requires `docs/evidence/reviews/prs/<slug>/security-audit.md`: `Head: <sha>` for the current HEAD, one line per `mitigate` and `accept` row (`TM-n: implemented <file:line>` with the file existing and the line being code, not blank, a comment or inside `=begin`/`=end`, `holds`, `stale`, `not implemented`) and a `VERDICT`. A missing, stale or incomplete record is exit 1, a `mitigate` row not implemented or an `accept` row gone stale is exit 3 for a human, and a red sweep means `guard-pr-ready.sh` refuses `gh pr ready`. The `security-auditor` agent and `/rails-flow:feature` carry the record's shape.
