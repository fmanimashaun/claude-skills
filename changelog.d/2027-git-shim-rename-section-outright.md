section: rails-flow
- **The git shim refuses every `git config --rename-section`, whatever the target — `plugins/rails-flow/git-shim/git`** (#2027, a0's measurement on #2024). #2024 refused a rename onto `alias` only. A rename onto `core` or `include` set `core.hooksPath`, `core.fsmonitor`, `core.sshCommand` or `include.path` past the per-key rules (`git config foo.hookspath /dev/null` then `--rename-section foo core`), because a rename never names the key it creates. Now every rename is refused: `--rename-section`, any unique prefix (`--ren` …) and the `rename-section` subcommand. The #2024 alias-only check is replaced. Selftest rows in `plugins/rails-flow/scripts/git_shim_selftest.py` for core, include, alias and a harmless target; three mutants in `plugins/rails-flow/scripts/mutations/git_shim.py` (the refusal, the prefix, the subcommand), each caught. Our own design; no framework claim.
