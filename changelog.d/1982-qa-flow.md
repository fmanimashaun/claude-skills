- **The shared command normaliser has an opt-in marker view, with no change for any rule that does not ask for it — `plugins/qa-flow/hooks/scripts/lib/normalize_cmd.sh`** (#1982). With `NC_MARK_EXPANSION=1` in the environment, `_dequote` leaves one `$` where it deletes a double-quoted span that holds a `$` or a backtick; rails-flow's `guard-bash.sh` reads the words of a `git add` that way (see the rails-flow entry for this change). The release gate sets nothing, so the text it reads is unchanged: `check_hook_gates.py --only release_gate` passes its 253 checks. The file is a byte-identical copy of rails-flow's, as `hook-lib-drift` requires.
