- **The release gate permits the files the certify flow's own stamp step writes — `plugins/qa-flow/scripts/release_evidence.py`, `plugins/qa-flow/hooks/scripts/release-gate.sh`, `plugins/qa-flow/scripts/remote_evidence.py`** (#1987). After the certified sha, the stamp step writes the report, `qa/certifications/<version>.md`; a README beside the authz sweep; and the dated CHANGELOG.md heading. The gate refused all three, so Retask had to move the stamp's `sha`. `stamp --rev` now also prints the stamp's report, but only when it is exactly `qa/certifications/<version>.md`, and the sweep folder's `README.md`, that one file and not the folder. The gate skips `CHANGELOG.md`. An app file, a code file beside the sweep, and a report the stamp does not name are each still refused by name; each case has a fixture in `check_hook_gates.py`, and mutants cover each permit and the narrowing. `remote_evidence.py --record` now defaults to a 180 s budget (judging keeps 8 s), because a real fetch took about 31 s. Our own design; no framework claim.
