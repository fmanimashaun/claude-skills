section: rails-flow
- **`/rails-flow:setup-flow` no longer prints its post-checkout hook inline — `plugins/rails-flow/commands/setup-flow.md`, `plugins/rails-flow/templates/post-checkout-graph.sh`** (#2022). Claude Code replaces a bare dollar-digit in a command's markdown with the arguments the command was invoked with (skills docs, "Available string substitutions"), so the hook's `$1`, `$2` and `$3` became the caller's words (`[ "Audit" = "1" ]`) when the command was run with arguments, and the branch-switch hook never fired. The hook is now a template file the command copies.
