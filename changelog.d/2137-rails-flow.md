section: rails-flow
- **`toolchain-selftests` runs one version per installed plugin, not every cached version of rails-flow, so an older cached `docs_layout.py` no longer fails the current git shim and blocks `gh pr ready` — `plugins/rails-flow/scripts/check_toolchain_selftests.py`** (#2137). In the installed layout (`<cache>/<plugin>/<version>/`) its own flat walk took `parents[1]` for the plugin directory, so "siblings" were other VERSIONS of rails-flow and the sibling plugins (qa-flow, design-flow) were never reached: on a Retask worktree it ran 124 selftests, 4 of them rails-flow versions, and the 1.60.1 and 1.61.0 `docs_layout.py` (no `.git/rails-flow-fixture` marker) failed `git add -A` under the 1.63.0 shim. It now uses `project_gates.plugin_roots`, the walk #706 already fixed for `project_gates` itself: the same worktree runs 53 selftests with 0 findings. A fake-cache-layout selftest and a guard mutant that restores the flat walk. Our own design.
