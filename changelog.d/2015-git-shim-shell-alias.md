section: rails-flow
- **The git shim refuses writing a shell alias through `git config`, in a marked fixture too — `plugins/rails-flow/git-shim/git`** (#2015, found by a2's attack pass on #2013). An alias whose value starts with `!` runs any command the next time it is used, and the shim cannot see inside it. `git config alias.x '!sh'` (and `--add`, `--local`, any case, a leading space) was allowed everywhere, including inside a fixture, whose exemption covers only `core.hooksPath`. Now refused; a plain alias write and an alias read still run, since a plain alias is judged again when used. New selftest rows in `git_shim_selftest.py` (a plain repository and a marked fixture) and two mutants in `plugins/rails-flow/scripts/mutations/git_shim.py`, both caught on macOS and on Linux. Our own design; no framework claim.
