- **The git shim refuses renaming a section to `alias` — `plugins/rails-flow/git-shim/git`** (#2023, follow-up to #2015, found by the commit security review of #2020). `git config foo.x '!sh'` then `git config --rename-section foo alias` made a shell alias without ever naming `alias.x` and a `!` value together, so #2015's rule did not see it. Renaming a section to `alias` or `alias.*` is now refused in every spelling git accepts: `--rename-section`, any unique prefix (`--ren`, `--rename-s`), and the `rename-section` subcommand. Renaming to any other section still runs. New selftest rows in `git_shim_selftest.py`, and three mutants in `plugins/rails-flow/scripts/mutations/git_shim.py`: the rename refusal, its prefix spelling, and (a0's review of #2020) the case-insensitive alias-key match. Our own design; no framework claim.
