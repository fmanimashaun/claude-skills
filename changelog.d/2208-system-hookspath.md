section: Repository hygiene
- **Fixtures no longer read the machine's git config — `plugins/rails-flow/scripts/fixture_git.py`** (#2208).
  - **The cause.** Homebrew's system gitconfig sets `core.hooksPath=.githooks`. Under it, a hook a selftest plants in `.git/hooks` never ran, so "the hook did not run" passed whatever the code did, and "it ran" failed for the wrong reason.
  - **The fix.** `fixture_git` (all three identical copies) and `scripts/hermetic_git.py` now set `GIT_CONFIG_NOSYSTEM=1`, so a Mac fixture behaves as the Linux runner's does. `wip_commit` scrubs every `GIT_*` from its own git, so its selftest keeps the machine's config and resolves the hook directory instead (#2207).
  - **The lint.** `lint_self_consistency.py`'s new `planted-hooks-not-hermetic` rule refuses a script that builds a `.git/hooks` path without one of three things: `rev-parse --git-path`, `GIT_CONFIG_NOSYSTEM`, or git run through `fixture_git`/`hermetic_git`. It also refuses either helper dropping the variable. The rule has 5 scenarios and 3 guard mutations.
