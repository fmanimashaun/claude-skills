- **`cd <worktree> && gh pr ready <n>` is accepted, judged on that worktree's HEAD record — `plugins/rails-flow/hooks/scripts/guard-pr-ready.sh`** (#2132). The guard refused every compound command, so a PR whose head is checked out in another worktree could only be marked ready by a session started inside it (the Bash tool does not carry a bare `cd` to the next call); it stranded #2131. Now exactly one extra segment is accepted: a `cd` to one plain literal path, joined by `&&`, the raw command at most 4096 characters; `lib/command_cwd.py` judges the record in that directory, and a cd cannot move HEAD. Everything else stays refused: a second segment, `;`, a second cd, a quoted or variable or substituted path, `-R`. 19 fixture rows, 3 mutants; the shell-adversary found nothing.
