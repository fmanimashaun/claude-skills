It reads the records as committed at the stamp's revision, calls GitHub only for a new-format record that lacks `Story:`, and ignores legacy records. If records exist and the reader is missing from the install, the stamp is refused by name (fail closed), never skipped. It reads the record lines with `plugins/qa-flow/scripts/mockup_records.py`, a byte-identical copy of rails-flow's, held by the `vendored-copy-drift` lint.
