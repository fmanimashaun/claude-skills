- **`check_criteria.py` maps `[security]` criteria to the threat model's `mitigate` rows — `plugins/rails-flow/scripts/check_criteria.py`** (#2118). Our-design change, no external claim. A unit with a threat model (`docs/security/threat-models/<slug>.md`, found beside its acceptance file or via `--threat-model`) is refused when a `mitigate` row (TM-1 is the first row of the Threats table) has no `[security]` criterion citing it, or when a `[security]` criterion cites no row or an `accept`, `transfer` or `eliminate` row. No model, no change. The `spec-reviewer` agent maps the same rows as `spec-missing` and `spec-unasked`.
