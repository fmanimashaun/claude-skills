section: qa-flow
- **The release gate answers a large command in under a second, and so does its fallback — `plugins/qa-flow/hooks/scripts/release-gate.sh`** (#1952, found by the qa-flow audit). Measured on dev: a command with a push to main took 3.1 s at 195 KB and 8.2 s at 390 KB, and gave no answer in 70 s at 683 KB; with a 3 s deadline even the 390 KB command got none. The cause is the degraded-mode fallback, which runs exactly when the gate is already late and is quadratic in bash 3.2 (`${x//a/b}` passes and a word loop): with no other work in the way, a 2 KB payload took 2 s, 6 KB took 22 s and 11 KB over 40 s. The harness kills a hook at 15 s and a killed hook lets the command run, so for a command of a few KB in a degraded path (a deadline or a missing tool) the gate was not a deny. Now a payload past 128 KB never enters the full path, and the fallback decides any payload past 2 KB with a few linear matches: does it name `git` or `gh`, in any case and with quotes or backslashes between the letters (`g"it"`, `g''it`, `g\it`, found missing by 8b's review), or contain an expansion (`$(`, `${` or a backtick) that could build either word (`G=gi; ${G}t push`, `$(printf gi)t push`). Not a verb list, which would let an alias or a quote-split verb through, as the precise rules already refuse them. The expansion rule fails CLOSED by decision: a command this large that expands anything is refused too; both answer in well under a second at any size and honour `QA_ALLOW_MAIN=1` with an audit line. Cost, accepted and said in the refusal: in those cases a command that merely mentions git or gh, or expands anything, is refused, and the message says to write the file with the Write tool and run a short command. Small commands take the unchanged precise path (the 249, 251, 76, 142, 113, 302, 239 and 99 checks of the other release-gate groups still pass). New group `release_gate_large` (14 checks plus 11 for the alias, case, split-word and expansion shapes) fails against the old hook; its guard `hook_release_gate_large` has 10 mutants, all caught on macOS and on Linux. A refusal that arrives within seconds is also what makes a harness timeout safe to add on top (#1939).
