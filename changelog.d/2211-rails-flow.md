section: rails-flow
- **The mock-up gate checks the mock-up is drawn inside the app's own shell, not only that a mock-up exists — `plugins/rails-flow/scripts/check_mockup_gate.py`** (#2211, the owner's ruling of 2026-10-21; our own design, no framework claim). Every mock-up record now carries `Shell: docs/product/mockups/shell.md`. That file is the project's one recorded shell: `check_mockup_gate.py --adopt-shell <screen-a.html> <screen-b.html> ...` derives its signature (the landmark elements and element ids two or more approved screens share), refuses a signature with no `main` or fewer than three tokens (an empty one passes every page), and writes the record only if it then passes; `--keep` narrows the signature, cannot add a token, and is recorded as `Shell-keep:` (the gate recomputes the signature from the sources and that list, so a hand edit fails either way). A mock-up that is a repo HTML file must hold every signature element (a word in text, a comment or a script string does not count, and neither does anything inside `<noscript>`, `hidden`, `aria-hidden="true"` or an inline `display:none`; the contents of a `<template>` do); an image or link is checked for the `Shell:` reference only and the output says so. A project with no recorded shell is held on its first user-visible change: that change is the shell. Once the shell is on the base, a change that touches only `shell.md` covers none of its views. Measured on a copy of a downstream project's 52 HTML mock-ups, adopting 2 screens and keeping the 10 layout tokens they share: of the other 50, 25 pass, and the 25 that fail have no shell in them (20 modal or overlay boards with a header and main but no nav and no page behind them, 4 flow diagrams with only a main, 1 with no landmark); no shell-shaped screen fails. **Migration:** only records a branch adds or changes are judged, never history; a modal or overlay is now drawn over the shell, not on a blank board; a project with UI work in flight and no recorded shell is held until it runs `--adopt-shell` (or declares `mockup-gate: off`). The record format is in `plugins/rails-flow/reference/mockup-record.md`; `/rails-flow:feature` Phase 1, `/rails-flow:fix` and the `pr-reviewer` agent say the mock-up leads and Claude Design import is optional.
