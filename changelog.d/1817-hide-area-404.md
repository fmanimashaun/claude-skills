- **rails-8: how to hide an area's existence — answer the app's ordinary 404, from a route constraint and the same check in the base controller — `skills/rails-8/references/ecosystem-gems.md`** (#1817). Pundit's documented `rescue_from` redirects, or answers 403 through `rescue_responses`. Both tell a refused visitor the area exists. For an area whose existence is a secret, the skill now says: refuse at a route constraint (a refused request finds no route, so every refused persona gets the 404 of an unknown path); repeat the same predicate in the area's base controller with `raise ActionController::RoutingError`; and back both with a route-map spec that expects 404 for each refused persona on every path under the area. The redirect stays the default for ordinary pages. Our own design, with no upstream: the maintainer's decision is https://github.com/fmanimashaun/claude-skills/issues/1817#issuecomment-6117790301. The framework facts it rests on (a refused route is a `RoutingError`, which renders 404) were verified for #1902.
