- **The release gate's degraded-PATH fixture tests a PATH again — `plugins/rails-flow/scripts/check_hook_gates.py`** (#1921). Since #1850 the hook rebuilds PATH from absolute entries outside the repository, and with no `.git` above the working directory the repository is that directory, so `bare_gate`'s tool directory inside it was dropped: "python3 and git present, no grep or sed" tested the same as "only bash", and the mutant that limits the fallback to a missing python3 survived the v1.156.0 sweep. The hook now runs in a sibling directory; the same mutant exits 0 and is caught. Our own design; no framework claim.
- **The harness guard's #1810 mutant is caught — `plugins/rails-flow/scripts/check_hook_gates.py`** (#1921). `check_hook_gates_harness` runs only the `timeout` group, and the check that the release-gate recorder keeps what the hook said lived in the `release_gate` group, so the mutant that drops the output survived the v1.156.0 sweep. The `timeout` group now drives `_said_recorder` directly with a finished process and asserts the detail carries its stdout and stderr; `--guard check_hook_gates_harness` no longer reports it. Our own design; no framework claim.
