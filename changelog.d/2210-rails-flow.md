section: rails-flow
- **A stack's security checklist and cases file each have one strict shape — `plugins/rails-flow/scripts/detect_stack.py`, `plugins/rails-flow/scripts/security_scope.py`** (#2210). Our-design change, the coordinator's rule from #2213: read as text, never interpreted as Markdown. `detect_stack.py --check` refuses a checklist holding a character outside printable ASCII plus `—` and `§` (so a look-alike citation, a zero-width or hidden character, a tab, or a line break only Python sees cannot pass), an HTML comment ("delete it, don't hide it"), any raw HTML (`<details>`, `hidden`), an HTML entity (`&#67;` renders as C), an image or a link title, a code fence or an indented code block, a link reference definition, a table row that does not start with `|`, or a claim id outside the `(C-n)` slot at the end of its line. A cited `C-n` must be a row of the one audit the checklist names whose first verdict line is exactly `Verdict: CONFIRMED` (a nested heading cannot lend it one), checked in a marketplace checkout. `security_scope.py` refuses a cases file that is not a non-empty list of objects with exactly `name`, `plan`, `paths`, `boundary`, typed, with a non-blank plan, no key given twice and unique names, and does not run it. rails-stack's checklist and 45 cases already pass. Two adversary rounds found every bypass this closes. Selftest rows cover each refusal and its near miss; 9 and 25 new mutants, all caught.
