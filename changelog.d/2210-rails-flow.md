- **A stack's security checklist and cases file each have one strict shape — `plugins/rails-flow/scripts/detect_stack.py`, `plugins/rails-flow/scripts/security_scope.py`** (#2210). Our-design change, the coordinator's rule from #2213: read as text, never interpreted as Markdown. `detect_stack.py --check` refuses a checklist holding an HTML comment ("delete it, don't hide it"), a code fence (indented or not), an indented table row, or a claim id `C-n` outside the `(C-n)` slot at the end of its line. `security_scope.py` refuses a cases file that is not a non-empty list of objects with exactly `name`, `plan`, `paths`, `boundary`, typed, names unique, and does not run it. rails-stack's checklist and 45 cases already pass. Selftest rows for each refusal and its near miss; 7 and 8 new mutants, all caught.
