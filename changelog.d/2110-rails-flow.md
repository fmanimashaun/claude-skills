section: rails-flow
- **The SessionStart hook leaves exactly one git shim on PATH, the running version's — `plugins/rails-flow/hooks/scripts/session-start.sh`** (#2110). The hook appended `export PATH=<shim>:"$PATH"` to `CLAUDE_ENV_FILE` once per DISTINCT line, so after a plugin update the env file held every version's line and an OLDER shim stayed first (a session had 1.61.0 ahead of 1.62.1, with 1.59.0 first and last in another), so the fixes of the newer shim never ran. The written line now strips every rails-flow `git-shim` directory (the cache layout `rails-flow/<version>/git-shim` and a checkout's `rails-flow/git-shim`) from PATH before prepending this version's, and an earlier version's line is dropped from the env file (other hooks' lines stay); when the strip cannot run or leaves nothing PATH is kept as it was, so a failure never empties it. `plugins/rails-flow/scripts/git_shim_selftest.py` gains rows for the rewrite, for one shim under bash and zsh (sourced twice stays one), and for the fallback; `plugins/rails-flow/scripts/mutations/git_shim_hook.py` gains four mutants and two stale anchors are repointed. Maintainer decision: the fix designed on #2110 (rewrite the env file without earlier shim lines, and strip every `*/rails-flow/*/git-shim` entry before prepending).
