- **`docs_layout.py` no longer calls a measurement script "code in docs/" when the report beside it runs it by path — `plugins/rails-flow/scripts/docs_layout.py`** (#2093). The three Ruby scripts of the native-code benchmark under `docs/evidence/benchmarks/2026-09-24-native-code/ruby/` made `project_gates.py` record a red sweep for every branch that contained them, so the pr-ready guard refused `gh pr ready` while the PR's own gates job was green. They are the reproduction: the report's Commands block runs `ruby --yjit ruby/bench.rb` from that folder, so moving them to `scripts/` would break every command and split them from the sibling `rs/`. The exemption is narrow and follows the existing canvas-module carve-out: a script is evidence only when a `REPORT.md` inside its own bundle (`docs/evidence/<kind>/<run>/`, never the `evidence/` or kind folder) names its relative path; a bare file name, a script the report never names, and a `REPORT.md` outside `docs/evidence/` still leave it code. Five selftest cases (one positive, four negatives) and a mutation in `scripts/mutations/docs_layout.py` hold it; replayed by hand, the mutants for the carve-out, the citation requirement, the evidence-tree restriction and the bundle depth each turn a named check red. The sibling `.rs` files were never flagged because `.rs` is not in `CODE_EXT`; that is left as it is. Our own design (a layout rule has no upstream), recorded on #2093.
