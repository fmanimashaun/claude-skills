section: nextjs-stack
- **The toolchain a Next.js, Supabase or Vercel project needs — `plugins/nextjs-stack/stacks.json`** (#2168). Next.js declares `nextjs-stack@claude-skills` and Docker (ready when `docker info` exits 0, which a recorded run on 2026-10-21 showed is exit 1 with the daemon unreachable). Supabase declares the official `supabase@claude-plugins-official` plugin, which bundles the `supabase` and `supabase-postgres-best-practices` skills, so we ship no Postgres doctrine of our own, and the `supabase` CLI (`npm install supabase --save-dev`, found in `node_modules/.bin/` too). Vercel declares `vercel@claude-plugins-official`, which bundles Vercel's skills (`vercel-cli`, `vercel-functions` and the rest), and the `vercel` CLI (`npm i -g vercel`). Both install commands were matched against the vendors' pages by `check_verdict_quotes.py` on 2026-10-21. The plugins are guidance, not `plugin.json` dependencies: a dependency is unconditional, and one that cannot install stops nextjs-stack from loading.
