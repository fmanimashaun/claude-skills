- **The git shim selftest for section renames passes on Linux — `plugins/rails-flow/scripts/git_shim_selftest.py`** (#2030, follow-up to #2027 / #2029). The #2029 rows checked whether `core.hookspath` was set at all after a refused rename; on Linux the hermetic repository already carries one, so the unmutated selftest failed there and three mutants could not be narrowed. PR CI runs `--fast`, which skips mutation coverage, so it was green. The rows now plant a unique value per key and check that value did not arrive, and each rename target has its own source section so a rename that got through under a mutant cannot use up the next row's.
