section: flow-suite
- **New plugin `flow-suite`: one install brings rails-flow, qa-flow and pipeline — `plugins/flow-suite/.claude-plugin/plugin.json`, `.claude-plugin/marketplace.json`, `README.md`** (#1684). A manifest of `name` and `dependencies` only, which the dependencies docs call a valid plugin whose install installs every dependency (https://code.claude.com/docs/en/plugins/dependencies#bundle-plugins-for-a-team, verified 2026-10-10). It ships no commands, agents or hooks, lives at `plugins/flow-suite/` because the release-notes tool reads `plugins/<name>/.claude-plugin/plugin.json`, and starts at `1.0.0` because `--strict` warns on a plugin with no version. It declares no dependency BETWEEN the flow plugins: measured, no script or hook in one reaches into another (each ships its own copy of a shared library, #906), and a hard dependency would end "plugins install alone"; that is a product decision, not made here. Our own design; no framework claim beyond the cited page.
