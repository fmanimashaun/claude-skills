**Suggested wording (about 105 words, uses CONFIRMED rows only):**
In Rails 8.1.4, ActionDispatch::Executor reports a request exception with `handled: false` and source `application.action_dispatch` on two paths. First, after the app returns normally, if ShowExceptions flagged an exception whose class has no rescue_responses entry. Second, whenever an exception propagates out of the inner app, regardless of rescue_responses. ShowExceptions re-raises when `show_exceptions` is `:none`, or `:rescuable` for a class with no entry. DebugExceptions renders and swallows the exception when `show_detailed_exceptions` is true; when false it re-raises to ShowExceptions. Defaults: development `:all` with detailed true reports nothing. Test (including Retask) is `:rescuable` with detailed true. Production is `:all` with detailed false.
